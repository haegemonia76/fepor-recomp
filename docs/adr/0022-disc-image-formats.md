# 0022 Disc image formats: RVZ and GCZ

Status: accepted (ticket M7.2, ADR 0010)

- `crates/core/src/image.rs` turns a file into the bytes of the GameCube disc: `open(path)` looks at the first four bytes and returns a plain GCM, a GCZ or an RVZ behind the `Image` trait (`len`, `read_at`, zero beyond the end). `IsoDisc` reads the disc file system through it, so `extract`, `analyze`, `prepare`, `ls`, the GUI and the game itself take `.iso`, `.gcm`, `.rvz` and `.gcz` alike, with the same `main.dol` check. Each format keeps the last block or group it decoded: the DVD driver reads mostly in order.
- **GCZ**: header, block table, zlib blocks (`flate2`, pure-Rust backend), blocks stored raw when their table entry says so. The per-block Adler-32 is not checked.
- **RVZ** (Dolphin's description, `docs/WiaAndRvz.md`): GameCube discs only, compression none or Zstandard, chunk sizes as written by Dolphin. The first 0x80 bytes come from the header; the raw-data and group tables are decompressed once at open. RVZ packing is decoded and the disc's pseudo-random padding (lagged Fibonacci generator, lags 32 and 521) is regenerated, aligned to the 32 KiB sector, so the image reads back byte for byte like the ISO. Wii discs (partitions, hash exceptions), WIA and the other WIA compressions (bzip2, LZMA) are refused with a message that says why.
- **Checked**: two real Dolphin RVZ files (Tales of Symphonia, 1.46 GB, Zstandard, 128 KiB chunks) against the ISO that `nodtool` (nod, another implementation) makes from them: every byte equal (`FEPOR_TEST_IMAGE=.. FEPOR_TEST_ISO=.. cargo test -p fepor-core --release real_image -- --ignored`), and `extract` gives identical `sys/` and `files/` trees from both. Not checked against a real file: GCZ (none at hand; the unit tests write one following Dolphin's `CompressedBlob` layout) and RVZ with the compression method NONE. The default tests use small synthetic images written by the test itself (stored and Zstandard groups, packed padding).
- **Dependencies and licences**: `flate2` (MIT OR Apache-2.0) with `miniz_oxide` (MIT OR Zlib OR Apache-2.0), and `ruzstd` (MIT) with `twox-hash` (MIT): all pure Rust, no C library to build, compatible with the project licence. `ruzstd` also provides the encoder the synthetic RVZ tests use.
