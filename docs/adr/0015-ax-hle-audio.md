# 0015 AX audio: ucode HLE and output

Status: accepted (amends ADR 0006)

- **Which ucode**: the game's DSP boot task is identified by the Ector hash of its IRAM image (`0x3ad3b7ac` for GFEP01, the "AX" family Dolphin also HLEs). `crates/runtime/src/ax.rs` emulates it; there is no DSP core.
- **Protocol**: after the boot task starts (`DSP_INIT`), each frame is `0xBABE0000|size`, then the command list address; the ucode runs the list on guest RAM/ARAM and answers `DSP_YIELD`; the CPU then sends `0xCDD10003` (continue). `0xCDD10000` resumes, `0xCDD10001` announces a new ucode (its ten upload mails are swallowed, `DSP_RESUME` follows), `0xCDD10002` hands the DSP back to the ROM.
- **Mixer**: 5 ms frames at 32 kHz. Voice parameter blocks (122 u16 words, layout from the AX GC structs), accelerator reads from ARAM (ADPCM, PCM16, PCM8, loop/stream handling), linear/nearest resampling, volume envelope, low-pass filter, 9 mix buffers (main/auxA/auxB x L/R/S) with ramped volumes, aux sends, compressor and output commands. Arithmetic follows Dolphin's DSPHLE (GPL-2.0-or-later) so results match it; deviations: polyphase resampling uses linear interpolation (the DROM coefficient table is not available), ITD and depop are not modelled.
- **Output path**: `CMD_OUTPUT` writes the frame into the game's AI DMA buffers (right word first, left second). The AI DMA registers drive a wall-clock timer (`Dsp::tick`, period = buffer length / sample rate; AICR.AIDFR set means 32 kHz): every elapsed period raises the AI interrupt and queues the buffer; `Hw::pump_audio` (called from the safe point in `intr::poll`, before the interrupt can be delivered) copies it from RAM to an `AudioSink`.
- **Sinks** (`crates/audio`): SDL3 playback stream on its own thread (SDL objects are not `Send`; queue capped at about 200 ms), and `FEPOR_DUMP_AUDIO=file.wav` for headless checks. `FEPOR_NO_AUDIO=1` disables the device. `FEPOR_TRACE=ax` logs voices and command-list activity.
- **Timing**: the VI retrace rate follows DCR.FMT (the game selects 60 Hz on this EU disc); keeping the region default (50 Hz) stretched 29.97 fps THP frames to 40 ms and left a 6.7 ms silence in every audio frame.
- **Known limits**: the dev backend (`-O0` generated C++) misses some 5 ms deadlines, which shows as short runs of silence; the production backend must be measured. Audio is not yet slaved to the video clock beyond both following the wall clock. DVD audio streaming (AIS) is not modelled.
